# tests/ — Automated Pytest Test Suite

## Purpose
Unit, integration, and regression tests for the entire HoroConsultant platform.

## Key Files
- `tests/conftest.py` — Pytest fixtures
- `tests/test_*.py` — Test modules
- `tests/fixtures/` — Test fixture data

## Commands
```bash
python3 -m pytest -v
python3 -m pytest project/tests/ -v
```
