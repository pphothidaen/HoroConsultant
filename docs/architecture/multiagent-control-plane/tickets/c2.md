# C2 — Canonical Control-plane Core

All tickets are `BLOCKED — C1`. PostgreSQL is production authority; SQLite is a
single-host semantic adapter. No provider/transport/local claim may write
canonical transitions.

The modular-monolith package boundary is literal: `domain/**` owns pure rules,
`ports/**` owns interfaces, `application/**` owns use cases, `adapters/**` owns
I/O, and `bootstrap.py` is the single composition root. Migration modules are
later isolated under `migration/**`.

## C2 checkpoint exit

C2 closes only with durable recovery and multi-host concurrency evidence. Local
SQLite or mocked unit passes cannot replace PostgreSQL/fault evidence.
