# 📜 Rule 03: API & Web UX Design Standards
> **Scope:** `project/main.py`, `project/api_router.py`, `project/static/*`

## 📌 Requirements
1. **REST Conventions**: Endpoints must follow standard versioning (`/api/v1/bazi/*`).
2. **Pydantic Validation**: All request and response schemas must use Pydantic models with clear descriptions.
3. **Glassmorphism Design Aesthetics**: Web UI (`project/static/index.html`, `style.css`) must enforce dark theme glassmorphism aesthetics, glowing 5-element indicators, and dynamic micro-animations.
